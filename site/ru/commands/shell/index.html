mip shell - интерактивная оболочка менеджера пакетов
  1. Команды
  2. shell

mip shell

Что это?

mip shell запускает интерактивную терминальную оболочку MIP. Внутри оболочки вы можете выполнять любые команды MIP без префикса mip, использовать встроенные команды вроде cd и pwd, автодополнение по Tab, навигацию по истории команд и многое другое. Это как мини-терминал для управления пакетами.

Синтаксис

mip shell

Псевдоним:

mip sh

Опции

Команда shell не имеет опций командной строки. Вся настройка осуществляется через интерактивный сеанс.

Встроенные команды оболочки

Внутри оболочки MIP доступны следующие встроенные команды:

Команда Описание
cd <dir> Сменить текущую рабочую директорию
pwd Показать путь к текущей директории
clear Очистить экран и показать логотип заново
exit / quit Выйти из интерактивной оболочки
help Показать полное меню помощи со всеми командами
version Показать текущую версию MIP
shell Сообщить, что вы уже находитесь в оболочке

Команды MIP

Все стандартные команды MIP работают внутри оболочки без префикса mip:

Основные:

  • install / i <pkg> — установка пакетов
  • uninstall / rm <pkg> — удаление пакетов
  • list / ls — показать установленные пакеты
  • update / up — обновить пакеты
  • search <q> — поиск в реестре
  • info <pkg> — информация о пакете
  • init — инициализация нового проекта
  • run <script> — запуск скрипта
  • exec <cmd> — выполнение бинарника

Информация и безопасность:

  • outdated — показать устаревшие пакеты
  • audit — аудит безопасности
  • doctor — диагностика системы
  • why <pkg> — почему установлен этот пакет?
  • feel — оценка состояния проекта
  • hello — информация о системе

Управление:

  • cache — управление кэшем
  • config — управление конфигурацией
  • alias — управление алиасами
  • registry — управление реестрами
  • dedupe — дедупликация зависимостей
  • ci — установка для CI
  • genlock — генерация lock-файла
  • workspaces — управление рабочими пространствами
  • bundle — сборка пакетов
  • clone — клонирование проекта
  • publish — публикация пакета
  • plugin — управление плагинами
  • exports — экспорт пакетов
  • language — смена языка интерфейса
  • global — управление глобальными пакетами

Возможности

Автодополнение по Tab

Нажмите Tab для автодополнения:

  • Имена команд — введите in + Tab → install
  • Имена пакетов — когда команда ожидает пакет (например, install, uninstall, info), дополнение берётся из манифеста установленных пакетов

История команд

  • Стрелка вверх (↑) — переход к предыдущим командам
  • Стрелка вниз (↓) — переход к следующим командам
  • История сохраняется в ~/.mip/shell-history.json (до 500 записей)

Горячие клавиши

Сочетание Действие
↑ Предыдущая команда
↓ Следующая команда
Tab Автодополнение
Ctrl+C Выход из оболочки
Ctrl+L Очистка экрана (строка ввода сохраняется)

Умная обработка префикса mip

Если вы введёте команду с префиксом mip (например, mip install express), оболочка обнаружит эту распространённую ошибку, покажет дружественное предупреждение и автоматически выполнит команду без префикса.

Экран приветствия

При запуске оболочка показывает:

  • ASCII-логотип MIP
  • Номер версии
  • Имя текущего проекта
  • Количество установленных пакетов
  • Текущий язык интерфейса

Приглашение ввода

Приглашение выглядит так:

mip имя-проекта ❯

Файл истории

История команд сохраняется в ~/.mip/shell-history.json. В нём хранится до 500 последних команд, и оно сохраняется между сеансами оболочки.

Частые ошибки

❌ Вы в оболочке, а не в CLI

Проблема: Ввод mip <команда> внутри оболочки (например, mip install lodash).

Что происходит: Оболочка обнаруживает эту распространённую ошибку, показывает предупреждение и автоматически убирает префикс mip, выполняя команду.

Совет: Внутри оболочки просто вводите команду напрямую: install lodash.

❌ Уже в оболочке

Проблема: Ввод mip shell, когда вы уже находитесь в оболочке.

Что происходит: Оболочка отвечает “⚠️ Already in shell!” и остаётся в режиме оболочки.

❌ Неизвестная команда

Проблема: Ввод команды, которая не существует.

Что происходит: Оболочка показывает “❌ Unknown command: <команда>” и предлагает использовать help для просмотра доступных команд.

❌ cd в несуществующую директорию

Проблема: Попытка перейти в директорию, которая не существует или недоступна.

Что происходит: Оболочка показывает “❌ cd: <сообщение об ошибке>” и остаётся в текущей директории.

💡 Совет
  • Оболочка отлично подходит для пакетных операций — вы можете выполнять несколько команд подряд без ввода mip каждый раз.
  • Используйте cd для навигации между разными MIP-проектами, оставаясь в том же сеансе оболочки.
  • История команд сохраняется между сеансами, поэтому ваши часто используемые команды всегда под рукой.
  • Если у вас установлено много пакетов, автодополнение по Tab для имён пакетов сэкономит много времени.

Связанные команды

  • mip hello — TUI с информацией о системе
  • mip list — список установленных пакетов
  • mip install — установка пакетов
  • mip exec — выполнение бинарников
